# Beautiful Souls — Version 1

A first static website for **Beautiful Souls**, designed as an evolving home for the foundational framework *A Healthy Belief System Towards A Meaningful Life*.

## Files
- `index.html` — homepage
- `framework.html` — framework map with the current Parts I and II, and a clearly marked developing Part III

- `reflections.html` — placeholder for future essays
- `about.html` — project introduction
- `styles.css` — responsive visual design
- `script.js` — Mobile navigation and current year

## Preview locally
Open `index.html` in a browser.

## Deploy with Cloudflare Pages
1. Push these files to the root of your GitHub repository.
2. In Cloudflare, open **Workers & Pages** → **Create+* → **Pages** → **Connect to Git**.
3. Select the `beautifulsouls` GitHub repository.
4. For a plain HTML Site, leave the build command empty and set the build output directory to `/` (or the repository root, depending on the Cloudflare setup screen).
5. Deploy. Cloudflare will provide a `|pages.dev` preview address.
6. After checking the preview, add `beautifulsouls.ca` as a custom domain in the Pages project.

## Content note
The framework page provides concise editorial summaries of the current manuscript's headings and arguments. It does not replace the full manuscript. Part III is intentionally marked as developing because the source document currently names that part without developed subsections.
